# 荣耀安卓实测 · 香港直连备用与 FastCat v2

2026-11-19（北京时间），在同一台荣耀 Android 12、同一 Wi-Fi 上，通过快猫系统 VPN 运行独立测试应用。VLESS 选用机主节点列表的「香港直连备用」，FastCat v2 选用 3.7.1 调试版直连入口。两条线路的成功 HTTPS 出口查询和 UDP 回复均指向同一公网出口，断开 VPN 时的出口不同。VLESS 传输期间的套接字也指向 v2 所在主机的另一个端口。

## 按手机现有设置访问域名

主测试在北京时间 18:45–19:05 进行，顺序为 VLESS、v2、v2、VLESS、v2、VLESS。固定 IP 诊断轮单列。每轮访问相同的 Cloudflare 和 Google gstatic 目标，每个目标先做一次预热，随后各发五次计分请求。每次重新建立目标 TCP/TLS 连接，校验证书，并验证 HTTP 状态及响应长度。首字节从安卓应用开始解析地址计到读到第一字节 HTTP 响应。中位数和 P95 只统计成功样本，失败另计。P95 取最近秩，小样本下容易受单次慢请求影响。

| 指标 | 香港直连备用 · VLESS | FastCat v2 |
| --- | ---: | ---: |
| 网页成功 | 30/30 | 24/30 |
| 两个目标合计首字节 P50 / P95 | 1,691 / 5,106 ms | 1,312 / 4,061 ms |
| Cloudflare 首字节 P50（成功数） | 1,153 ms（15/15） | 941 ms（11/15） |
| Google gstatic 首字节 P50（成功数） | 2,012 ms（15/15） | 2,048 ms（13/15） |
| 1 MiB 完整下载速率中位数 | 2.86 Mbps（6/6） | 3.55 Mbps（4/6） |
| UDP 收到匹配的回复 | 18/18 | 15/18 |
| 成功 UDP 回复 P50 | 590 ms | 222 ms |

v2 两次从 VLESS 切回后，各有三次计分请求在 TCP 建连前报 `UnknownHostException`，测试应用没能取得可用 IPv4。这两轮均为 7/10，保持 v2 连着的另一轮为 10/10。连预热也计入，两条线路的网页成功数分别为 36/36 和 26/36。v2 按客户端默认策略自动选路。前两轮后，以及第三轮随后的固定地址补测后，状态页均显示最近一次 TCP 使用 HTTP/2，UDP 已接通。状态页仅记录最近一次 TCP 连接。

下载指标使用 Cloudflare 相同的 1 MiB 对象，从新建连接到完整收到内容计算，包含建连开销。成功下载的速率范围为 VLESS 2.06–4.30 Mbps、v2 0.64–6.47 Mbps。v2 两次未完成的下载分别报套接字超时和 TLS 握手异常。UDP 使用 Cloudflare STUN 的 3478/UDP，每次新开套接字只发送一个请求，按事务编号校验回应，等待上限 3 秒。UDP 用时包括此次业务在网关建立关联的时间，区别于持续发送游戏数据时的单包延迟。[Cloudflare 测速端点](https://github.com/cloudflare/speedtest) · [Cloudflare STUN](https://developers.cloudflare.com/realtime/turn/)

## 固定目标 IPv4 的补充测试

两条线路分别向同一对 IPv4 发起请求，保留原 HTTPS 主机名、SNI 和证书校验，跳过测试应用主动查找目标地址的步骤。两次诊断不计入主测试。

| 计分指标 | 香港直连备用 · VLESS | FastCat v2 |
| --- | ---: | ---: |
| 固定地址网页成功 | 10/10 | 9/10 |
| 成功请求首字节 P50 | 816 ms | 1,511 ms |
| 固定地址 1 MiB 下载成功 | 2/2 | 0/2 |

另外一次刚重连 v2 就使用固定地址，2 次预热和 4 次计分网页请求均成功。正常按域名访问时的启动失败值得单独查 DNS。固定地址对照中仍出现 TLS 握手失败和下载超时，尚不能把全部差异归因于 DNS。

这次对比反映两条实际配置在这台手机及其 Wi-Fi 上的表现。优先保证网页能打开、文件能下完时，VLESS 在本轮更可靠。v2 成功样本的网页首字节和 UDP 回包中位数更低，但成功率仍落后。

测完已恢复手机原有的 Wi-Fi、VPN 断开状态、订阅与节点选择设置，并移除临时测试应用。快猫重新打开时刷新了同一订阅的本地快照。

## 19:19–19:23 · 安卓 DNS 修复后的复测

对于安卓 v2 直连配置，应用停止向常规 DNS 上游自动加入 `system://`。VPN 启动后系统解析器可能被指回 VPN 的 DNS 地址。应用继续使用已有 DNS 上游设置。

同一台荣耀手机和同一 Wi-Fi，使用前述两个 HTTPS 目标。顺序为 VLESS、v2、v2、v2、VLESS、VLESS。每轮重开探测应用，记录系统 VPN 生效后开始的全部 10 次请求，含每个目标的首次请求。首字节从解析域名开始计时，耗时分位数取成功样本。本轮集中验证冷启动解析和短 HTTPS 请求。

| 指标 | 香港直连备用 · VLESS | FastCat v2 修复版 |
| --- | ---: | ---: |
| 网页成功 | 29/30 | 30/30 |
| DNS 失败 | 0 | 0 |
| 首字节 P50 / P95 | 1,259 / 4,344 ms | 690 / 2,035 ms |

VLESS 有一次 Cloudflare 请求在 TLS 握手阶段超时。v2 三次重连后均为 10/10，上一轮观察到的六次 IPv4 解析失败未复现。本轮尚无新的下载与 UDP 数据。手机保留修复版及已导入的 v2 配置，返回订阅并断开 VPN。
