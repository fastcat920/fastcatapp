# v2 优化后与最新轻量版安卓对照（2026-11-21）

## 变更与验证

CatNode 的 v2 目标 TCP 拨号由逐个串行尝试改为最多两路错峰尝试，默认间隔 250 ms，优先给另一地址族机会；快速失败立即补位，成功后取消并关闭落败连接。单地址直接拨号。保留全部 DNS 答案先校验、固定数字 IP 拨号、总体超时及 UDP 原有行为。新增可选、不记录域名/IP/凭证的拨号阶段耗时日志，正式对照未开启。

完整 fastcatv2 回归及竞态检查通过；go vet 通过；最终 h2server 竞态测试连续三轮通过。覆盖首选地址阻塞、取消、快速失败和迟到成功连接回收。源码位于 CatNode/internal/fastcatv2/h2server/target.go 和 target_test.go。

## 方法

同一安卓 A3GMVB2110006859、同一 Wi-Fi（前后默认网络均为 171）、同一香港服务器，独立端口 19442/19444；服务端 Go 1.27.3，测试客户端 Go 1.26.2。对照最新 v3-light-fast（IndependentPipelined），使用标准 TLS 校验、固定入口 IP，不启用 ECH/DoH。通过安卓独立核心测试程序运行，并非正式 App 端到端测试。

每协议/载体：冷启动20次、复用20次（轮换3个会话池）、四路并发5批共20次。交替测试，目标 example.com:443，HEAD 返回200视为成功。另有12次预热，不计入下表。首字节包括入口/目标建立至响应，P95采用成功请求排序最近秩；失败独立保留，不能把成功样本P95当作含超时的总体验。

## 结果

| 场景 | v2 成功 | v2 P50 / P95 ms | 轻量版成功 | 轻量版 P50 / P95 ms |
|---|---:|---:|---:|---:|
| H2 冷启动 | 19/20 | 1566.3 / 3656.4 | 20/20 | 1519.8 / 4365.0 |
| H3 冷启动 | 20/20 | 870.1 / 2292.7 | 20/20 | 1156.6 / 2639.1 |
| H2 复用 | 20/20 | 659.5 / 2116.4 | 20/20 | 613.6 / 3125.9 |
| H3 复用 | 20/20 | 531.0 / 841.5 | 20/20 | 649.6 / 1617.3 |
| H2 四路并发 | 20/20 | 851.0 / 1605.5 | 20/20 | 713.4 / 947.2 |
| H3 四路并发 | 20/20 | 569.4 / 872.1 | 20/20 | 703.0 / 974.9 |

v2 正式请求119/120，轻量版120/120。v2 的唯一失败为 H2 冷启动入口 context deadline exceeded，发生在目标拨号之前，当前目标拨号优化不覆盖该阶段。

本轮 v2 的 H3 三种场景 P50/P95 均更低；轻量版 H2 三种场景 P50 更低，并发 P95 更低。v2 H2 复用 P95 较低，但存在个别更慢请求，完整分布见原始数据。不能据此宣称 v2 在所有场景更快或更稳定。

本轮没有同轮未优化 v2 对照，也未开启服务端拨号诊断，无法把数值变化因果归于本次优化；该优化对首选目标地址不可达的作用由故障注入测试验证。单网络、单目标、每组20次不能推断长期可靠性、吞吐、耗电或抗识别能力。
