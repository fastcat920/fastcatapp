# FCN v3 第三阶段 · 自适应写入与限量填充

第三阶段实现和测试已完成。**目前保持现有写入为默认。** 自适应写入改善了这轮单路下载中位数，但四路下载有一批正文超时。有限填充改变了小请求的报文统计，下行报文长度 P95 保持相同。现有样本不足以作为隐蔽性结论。

| 选项 | 实际行为 |
|---|---|
| 现有写入 | 使用第二阶段的 64 KiB 复用缓冲，读到即写 |
| `-adaptive-writes` | 从 8 KiB 开始，连续满读时转至 128 KiB，连续短读再缩小。读到的数据立即发送 |
| `-limited-padding` | TCP 首个成功下行 DATA 载荷在 1–512 B 时，可附带一次 32–128 B 的 HTTP/3 保留帧。QUIC 无法立即排队时跳过。每个 QUIC 连接最多 512 B 序列化帧开销 |

填充与自适应可分别启用。应用字节完全一致，半关闭照常工作。真实 HTTP/3 回环测试中，自适应加填充的连接累计发出 512 B 保留帧，关闭填充的两组为 0 B。该帧类型定义允许使用保留帧作为应用层填充。 [HTTP/3 保留帧与填充](https://www.rfc-editor.org/rfc/rfc9114.html#section-7.2.8)

## 安卓公网性能

2026-11-25 在同一荣耀安卓、Wi‑Fi、`zlhk.fastcat.lol` 和同一校验源上跑 76 个批次。基线 FCN、仅自适应、自适应加填充和 TUIC 使用不同实验端口，轮换顺序。入口证书与目标校验条件相同，QUIC 均配置 BBR。此组专测写入，不开启 ECH，以便隔离对照因素。

| 指标 | 现有写入 | 自适应 | 自适应＋限量填充 | TUIC v5 |
|---|---:|---:|---:|---:|
| 正文校验成功 | 142/142 | 138/142 | 142/142 | 142/142 |
| 256 B 连续请求首字节 P50 / P95 | 320 / 871 ms | 256 / 665 ms | 235 / 1073 ms | 360 / 975 ms |
| 四路请求首字节 P50 / P95 | 111 / 452 ms | 116 / 843 ms | 114 / 669 ms | 108 / 700 ms |
| 4 MiB 单路吞吐中位数 | 13.27 Mbps | 18.77 Mbps | 11.07 Mbps | 16.82 Mbps |
| 四路 1 MiB 合计吞吐中位数 | 3.54 Mbps | 3.56 Mbps | 13.16 Mbps | 20.15 Mbps |

小请求有 4 批，各 16 条，相邻请求间隔 150 ms。首字节统计排除每批第一条。四路请求为每条 128 KiB、每批 16 条、共三批。单路和四路下载各六轮，吞吐统计含建连、校验和关闭。失败轮算入速率。自适应第三轮四路下载共用一条 QUIC 连接，四条都已收到首字节（约 1.53 秒），之后正文未在 25 秒内校验完成。**此次未定位到具体丢包、窗口或调度事件。** 该组第三轮完整保留，其他五轮均通过。速率波动大，暂不依据单次对照切换默认配置。

## 可观测报文特征

对小请求完整批次统计服务端到手机的 QUIC UDP 载荷。每组已校验应用载荷为 16,384 B。

| 抓包指标 | 现有写入 | 自适应 | 自适应＋限量填充 |
|---|---:|---:|---:|
| 下行报文数 | 363 | 330 | 392 |
| 下行 UDP 载荷总量 | 86,696 B | 83,870 B | 96,264 B |
| 下行报文载荷 P50 / P95 | 50 / 1280 B | 55 / 1280 B | 50 / 1280 B |

相对仅自适应，填充配置的小请求下行采样字节多 **14.8%**。该数值包含握手、控制报文、ACK、重传，以及网络和网卡分段合并的影响。两个配置的差值不能直接等于应用层填充量。抓包仅覆盖本次端口，按 UDP 头取得长度，未解密业务。四个工作负载的抓包内核 drop 计数均为 0。单路和四路大文件也保存了按配置和方向汇总的报文长度分布。当前数据只说明包长分布与开销观察，未测识别率。 [HTTP/3 填充局限](https://www.rfc-editor.org/rfc/rfc9114.html#section-10.7)
