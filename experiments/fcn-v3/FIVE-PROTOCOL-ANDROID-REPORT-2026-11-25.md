# FCN v3、FCN v2、FCN v1、TUIC v5、Hysteria 2 安卓公网对照

2026 年 11 月 25 日，使用同一台安卓、同一已验证 Wi‑Fi、同一香港服务器及同一确定性源站。用安卓原生核心比较入口和转发，直接运行测试程序。目标为服务端回环 HTTP 和 UDP 回显，不经过公网网站，保持源站负载一致。

每项五轮，每组各占据一次第 1 至第 5 个出场位置。FCN v1 和 v2 共用 CatNode 的同一个 FCN/1 监听器与凭证，只改变客户端单连接和恢复选路。FCN v3 使用普通固定 64 KiB 写入和 H3 CONNECT。TUIC 使用 v5，配置 BBR，关闭 0-RTT。Hysteria 2 使用 CatNode 原生处理器，采用默认带宽策略，未配置固定带宽、强制 Brutal 或混淆。各组使用同一张临时证书和域名校验。

| 工作负载 | 每组数量与口径 |
| --- | --- |
| 冷启动 | 20 次 4 KiB 请求，每条使用新客户端，首字节包含连接和源站响应 |
| 连续请求 | 40 次 4 KiB 请求，五批各八次，间隔 150 ms，首字节统计排除每批第 1 次 |
| 单路下载 | 五次 4 MiB，整批有效 Mbps = 完整校验字节 ÷ 批次耗时 |
| 四路下载 | 五批，每批四个 1 MiB 响应并发 |
| 单路上传 | 五次 1 MiB，源站校验字节并回执后才计为成功 |
| UDP | 五批，每批 28 包，64、256、512、900、1000、1100、1150 B 各四包，单包回显时限 1.5 秒 |

四路下载预算为 30 秒，单路下载 35 秒，上传 25 秒。吞吐包含建连、校验和批次收尾，同一口径比较。UDP 主比较为共同的 64–1100 B 载荷，1150 B 单列。失败保留，下载和上传仅将完整校验的业务字节计入吞吐。

预检五组的 TCP 和 UDP 均通过。初试因本地结果盘空间不足在冷启动第 1 轮中断，清理可重新生成的旧编译缓存后开启完整平衡测试。中断样本单独保存。 [预检记录](results/fcn-five-android-2026-11-25-preflight) · [中断原始样本](results/fcn-five-android-2026-11-25-io-interrupted)

## TCP 性能

五组共 **450/450** 条 TCP 样本校验通过，每组 90 条。连续请求的首字节分位数按每组 35 条复用样本计算。吞吐按五批的中位数计算。

| 协议 | 冷启动首字节 P50 / P95 | 连续请求首字节 P50 / P95 | 单路下载 P50 | 四路合计 P50 | 上传 P50 |
| --- | ---: | ---: | ---: | ---: | ---: |

| FCN v2 | 278 / 802 ms | 260 / 738 ms | 16.73 Mbps | 20.81 Mbps | 8.97 Mbps |
| FCN v1 | 335 / 965 ms | 247 / 473 ms | 19.38 Mbps | 20.20 Mbps | 8.88 Mbps |
| TUIC v5 | 395 / 2,495 ms | 222 / 404 ms | 18.61 Mbps | 9.80 Mbps | 8.96 Mbps |
| Hysteria 2 | 385 / 1,421 ms | 106 / 368 ms | 19.80 Mbps | 5.50 Mbps | 6.61 Mbps |

四路正文最大无进展间隔 P95 依次为 FCN v3 **491 ms**、FCN v2 **404 ms**、FCN v1 **388 ms**、TUIC **497 ms**、Hysteria 2 **504 ms**。FCN v2 的四路吞吐中位数最高，和 FCN v1 接近。FCN v1 的单路吞吐中位数高于 v2。两者共用同一入口，v2 在五轮中的四轮冷启动中位数比 v1 低，v1 在五轮中的四轮连续请求中位数比 v2 低。

Hysteria 2 的连续请求中位数约 106 ms，单路下载五轮范围 **17.02–22.61 Mbps**，四路为 **4.23–9.32 Mbps**。TUIC 的四路结果范围 **4.89–23.21 Mbps**，反映批次间波动。FCN v3 的连续请求中位数与 TUIC 接近，四路吞吐中位数高于 TUIC，单路与上传低于其他四组。本轮不同协议的入口端口、核心及拥塞控制实现存在差异。结果适用于这台设备、该 Wi‑Fi 和这次负载，未测蜂窝、切网、长锁屏或完整 VPN 界面的业务表现。

正式测试期间本地存储再次中断四路下载第 4 轮。保留原轮记录后，在同一个已验证 Wi‑Fi 重跑整轮，其余完成的批次保持。 [四路第 4 轮中断记录](results/fcn-five-android-2026-11-25-interrupted-parallel-round-04)
