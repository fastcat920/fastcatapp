# 五协议安卓反序复测

2026 年 11 月 25 日晚，继续在同一台安卓、同一 Wi‑Fi 默认网络、同一香港服务器和确定性源站上测试 FCN v3、FCN v2、FCN v1、TUIC v5、Hysteria 2。

每种工作负载五轮。把上一轮每个五组批次的出场顺序完全反转，原第 1/5、2/4 位各互换，第 3 位不变。例如首个冷启动轮从 **FCN v3 → FCN v2 → FCN v1 → TUIC → Hysteria 2** 改为 **Hysteria 2 → TUIC → FCN v1 → FCN v2 → FCN v3**。每组仍各占据一次第 1 至第 5 位。工作负载的执行先后、入口端口、轮数、超时、客户端及服务端二进制保持一致。预检单独留存。每组 90 个 TCP 样本和 140 个 UDP 样本。

连续请求首字节排除每批第一次，只统计成功的复用请求。失败和截止时间纳入整批有效吞吐。UDP 比较 64–1100 B 共同载荷，1150 B 单列。两次运行处于不同时间窗，比较可以观察排名对调度顺序与时段的敏感性，无法单独估计顺序对性能的因果影响。

## 与原顺序复测相比

| 指标 | 上一轮领先 | 反序领先 |
| --- | --- | --- |
| 冷启动 P50 | FCN v3 · 323 ms | FCN v1 · 487 ms |
| 连续首字节 P50 | TUIC · 293 ms | FCN v1 · 223 ms |
| 单路下载 P50 | FCN v2 · 15.41 Mbps | FCN v3 · 15.33 Mbps |
| 四路下载 P50 | TUIC · 18.47 Mbps | TUIC · 13.20 Mbps |
| 上传 P50 | FCN v1 · 7.88 Mbps | FCN v2 · 8.55 Mbps |

单路下载的 FCN v3 在原顺序从 **2.22 Mbps** 升到反序的 **15.33 Mbps**。反序第 1 轮它最后出场，测得 **18.57 Mbps**，第 2 轮最先出场也测得 **15.33 Mbps**。冷启动和连续请求里，首尾互换之后的变化方向在不同轮次交替出现。连同两次同序跑出不同名次的结果，目前看不到一致的早测或晚测优势。

第 3 位固定的匹配样本也有明显变化。例如 FCN v3 单路第 4 轮在两次都排第 3，吞吐从 **2.22** 升至 **17.63 Mbps**。第 3 位的前后相邻协议在反序时改变，公网时间也不同，因此不能把差异单独归到位置或协议相邻顺序。

共同载荷回显合计从上一轮 **457/600** 降至 **432/600**。全部 700 个计划包均有记录。40 个因载荷上限拒绝提交，660 个完成提交，其中 480 个校验通过，180 个等待回显超时。174 个超时的探针有对应的源站收包和发出回显记录，6 个没有源站收包记录。本轮只核验源站回执。

原顺序复测发生于北京时间 **19:32–19:53**，反序发生于 **20:20–20:43**。已逐批检查 150 个批次的实际开始和结束记录，顺序与计划一致，未重叠。安卓默认网络前后保持同一个已验证的 Wi‑Fi。17 条 TCP 失败均可匹配完整的源站写入回执。本轮 TCP、UDP 失败及预检记录均保留。临时测试监听、凭证和设备文件已清理。
