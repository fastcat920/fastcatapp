# FCN v3 第一阶段验收

**原型已实现，功能验收通过，性能未达到全部验收线。** 目前应继续定位首次建连和下载慢轮，不进入填充阶段。

2026-11-25 13:33:38–13:37:46（北京时间），在荣耀 TFY-AN00 的 Wi‑Fi 上测试。FCN v3 和 TUIC v5 共用 `zlhk.fastcat.lol` 对应的服务器和目标源，分别监听临时 UDP 18532、18533。两者使用同一张短期测试证书，安卓测试工具显式信任证书并校验名称。入口使用同一个 IPv4，指标排除了 DNS 查询时间。每批均核对安卓的默认网络为已验证 Wi‑Fi。

条件为 P50 ≤ 基线 110%，P95 ≤ 基线 115%，两项下载均 ≥ 基线 90%。每种协议 30 条新入口、60 条连续请求、48 条四路并发请求和 36 条吞吐请求。连续延迟统计从每批第二条开始，共 57 条。吞吐展示六轮完整批次速率的中位数，包含入口建立、业务和清理时间。单路下载成对比值的中位数为 104.0%，而两组速率中位数之比为 76.5%。后者是本报告的门槛口径。样本显示明显的轮次波动。

两端均使用各自实现的 BBR，关闭 0-RTT，使用相同入口地址、证书、负载和目标。QUIC 库版本、BBR 实现与默认窗口存在差异。结果适用于当前 FCN v3 和 CatNode TUIC 实现，不把差值全部归到 HTTP/3。

## 已定位的成本

1. **冷启动差距随链路波动变化。** 公网入口阶段 P50 是 121.6/125.3 ms（FCN v3/TUIC），从入口返回到首字节的 P50 是 114.9/103.9 ms。三轮冷启动首字节 P50 比为 1.14、1.58、1.69。各阶段分位数来自各自样本分布，不能相加解释整体 82.8 ms 的差距。Mac 回环冷启动 P50 为 2.852/2.804 ms，未复现同数量级的差距。当前可定位到冷连接和首请求阶段，尚缺证据确定具体包或调度事件。
2. **并发尾部受首次建连影响。** FCN v3 最慢的四条小并发请求都来自同一批的首波，入口等待约 433 ms，较慢请求首字节 646 ms。同批四个请求共享该 QUIC 连接。去掉每批首波后，P95 为 238.2/205.2 ms，相差约 16.1%，因此首次建连解释了大部分差距，复用阶段边缘仍待复测。这是定位视图，未替换主测门槛。
3. **下载存在独立的正文慢轮。** FCN v3 单路正文速率中位数为 17.14 Mbps，TUIC 为 22.03 Mbps，因此入口建立成本无法解释全部下载差值。四路中最慢的一批共享约 4.56 秒的入口等待，随后每流正文读取仍耗时约 3.2 秒。本机回环单路 / 四路吞吐分别保留约 105% / 97%，说明公网结果无法仅用本机 HTTP/3 帧处理成本解释。后续宜在固定 RTT、丢包与接收窗口下抓取匿名握手阶段、发送窗口和重传计数，先复核首波和正文慢轮。

## 功能验证

- 真实 HTTP/3 网页和 CONNECT 隧道共用 QUIC 入口。客户端使用同一连接上的独立流，服务端成功授权后才拨明确允许的目标。每条证明绑定 TLS exporter、目标和流编号。
- 安卓错凭证明确拒绝。热更新为全撤销后，新连接 2/2 拒绝，恢复后 2/2 成功。本地测试还验证在用隧道被撤销，另一侧观察到流取消。
- 本地验证双向半关闭、四并发流、连接复用、目标限制和证明跨连接/跨流复用拒绝。安卓单客户端间隔 1 秒执行 120 次，120/120 校验成功，用时 159.8 秒。
- Linux 服务端和安卓测试客户端可独立构建。测试基于普通 HTTP/3 CONNECT，FCN v3 与 TUIC v5 在应用协议层不兼容。加密由 QUIC 的 TLS 1.3 提供，业务层只增加授权与生命周期。 [HTTP/3 CONNECT 规范](https://www.rfc-editor.org/rfc/rfc9114.html#section-4.4)

测试部署首次使用的证书密钥采用了服务器库无法解析的 ECDSA 参数。修正为两条测试入口共用的 RSA 证书后完成预检，失败启动日志保留在证据中。本轮只覆盖授权 TCP 转发和数值地址允许列表。ECH、额外填充、UDP 转发、App 与面板集成留在后续阶段。
