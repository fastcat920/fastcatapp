# FCN v3 同网端口交叉与 UDP 回程复测

2026 年 11 月 25 日，在同一台安卓、Wi‑Fi 默认网络、香港测试服务器和确定性源站上执行。先完成四路下载，再执行 UDP。候选版只开启自适应写入；FCN 两组使用同一二进制。TUIC v5 固定端口 18533。入口使用同一受信测试证书，普通 TLS 1.3，两版 FCN 均关闭填充和 ECH。实验层只新增观测。

## 四路正文

映射 A 为现有版 18532、自适应版 18534。映射 B 对调这两个端口。每个映射各跑完三组顺序的六种排列，按 A→B、B→A 交替安排相同排列。各组每批并发下载四份 1 MiB 文件，超时仍使用 25 秒。

| 组别 | 校验完成 A / B | 整批有效吞吐 P50 A / B | 正文读间隔最大值的 P95 A / B | 最长正文读间隔 A / B |
| --- | ---: | ---: | ---: | ---: |
| 现有 FCN v3 | 24/24 / 24/24 | 18.08 / 8.29 Mbps | 381 / 553 ms | 486 / 585 ms |
| 自适应写入 | 24/24 / 24/24 | 8.98 / 7.20 Mbps | 558 / 563 ms | 760 / 599 ms |
| TUIC v5 | 24/24 / 24/24 | 8.79 / 19.30 Mbps | 1,193 / 485 ms | 1,247 / 595 ms |

144 条流均校验通过，两版 FCN 的正文读间隔最长 760 ms，旧轮的 25 秒超时未复现。自适应版在 12 个配对批次赢 5 次。两种端口映射里的吞吐中位数皆较现有版低，差距约从 50% 缩到 13%。TUIC 端口保持相同，两组穿插批次的吞吐中位数也从 8.79 波动到 19.30 Mbps。综合看，差距没有稳定跟随某一个端口，数据也不足以把幅度归因于自适应写入。继续保留固定 64 KiB 为默认。

- 现有版 B 的第 4 轮，入口阶段耗时约 4.42 秒，首字节 4.53–4.65 秒，该批最长正文停顿 457 ms。这里的慢主要发生在收到首字节前。
- TUIC A 的第 2 轮，有请求首字节约 0.37 秒，正文持续约 22.25 秒，最长读间隔约 1.25 秒，最终收完。正文缓慢也出现在对照协议里。
- 首次启动时测试凭证在归档解包后保留了 Mac 的文件所有者，FCN 拒绝启动。修正所有者后完成正式样本，启动日志单独保留，期间没有发出下载请求。

144 份源站回执均写满 1 MiB，最长 26.10 ms。映射 B 的自适应版第 2 轮，最慢流的源站写入耗时 6.74 ms，安卓正文读取 9.14 秒。该共享 QUIC 连接判定丢失 1,119 个包，出现探测超时计数更新，未记录流控阻塞帧。这个现象支持本轮慢批主要花在传输和恢复。丢包判定包括可能的乱序，源站写完表示本机接受写入。四路一同卡至 25 秒的直接触发条件仍未复现。

## UDP 回程

采用映射 A，三组继续轮换全部六种顺序，每组发 168 包。等待窗口仍是 1.5 秒，超时后继续下一包。所有组启用相同的接收观测，批次结束后最多再监听 1.5 秒，以捕获迟到报文。服务器仅捕获三个测试入口端口的出站 UDP，安卓在 UDP 套接字把数据交给客户端核心前记录指纹。只保留时间、长度和加密数据报的散列前缀用于对照。

| 配置 | 正确回显 | 超时 | 未到源站 | 源站已回显，唯一出站候选在安卓未见 | 成功回显 RTT P50 / P95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 现有 FCN v3 | 161/168 | 7 | 0 | 7 | 103 / 189 ms |
| 自适应写入 | 147/168 | 21 | 1 | 20 | 102 / 354 ms |
| TUIC v5 | 140/168 | 28 | 3 | 25 | 102 / 351 ms |
| 合计 | 448/504 | 56 | 4 | 52 | — |

56 次超时里，有 52 次源站提交了回显。每次都能按成功样本校准过的报文长度和服务端时间找到唯一出站候选，但安卓 UDP 套接字内没有相同指纹。此结论以时间、长度推定回显与加密报文的关联。其余 4 次源站没有收到请求，无法归到回程。

服务端采集 1,457 个加密数据报，抓包内核报告丢弃 0。安卓实际读取的 1,300 个数据报均匹配服务端出站指纹，接收记录报告丢弃 0。157 个服务端数据报没有安卓读记录，这个数包括 QUIC 控制包。两版 FCN 的应用回显数也与其 QUIC 入站、出站 DATAGRAM 计数一致。证据将大多数超时进一步缩小到服务端出站点至安卓 UDP 套接字读取之间。服务端出站采集发生在内核，仍无法区分网卡发送、沿途、安卓内核接收或套接字队列。

现有版的回显成功率从上轮 79.8% 到本轮 95.8%，TUIC 从 83.3% 到 83.3%。这是独立时段测试，样本间波动明显。候选版的自适应写入只改变 TCP 下行，UDP 差值不用于评价该开关。生产配置维持。
