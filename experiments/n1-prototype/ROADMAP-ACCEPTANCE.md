# Ordered TCP prototype acceptance

User scope: TCP web first; UDP deferred (user confirmed). Same connected Android, SIM now loaded; Wi-Fi + cellular comparison authorized. No standard APK, panel or production nodes changed. Work in independent lab ports. No claim of undetectability or independent cryptographic audit.

1. Stability: distinguish DNS, TCP, TLS, auth/target headers, body progress, FIN, outer EOF and TLS close. Respect setup cancellation/absolute budgets. Diagnose historical failures using retransmission/ACK/window metadata, compare N1 with ordinary TLS and a diagnostic smaller ClientHello, Wi-Fi vs cellular. Preserve failures. Never replay data after business writes. If a physical path remains impaired, report that boundary rather than inflate deadlines or erase failures.
2. Performance: matched baseline/capped server profiles, small/large responses, 1/4-way concurrency, ten-minute bounded sustained use, CPU/RSS/heap/goroutines/fds/active sessions. Promote capped layout in lab only if integrity/closure pass and no material reproducible throughput/resource regression. Report tails and timeouts, not successful-only averages. No broad production default changes.
3. Traffic observations: real Android browser, ordinary native HTTPS and normal streaming controls; varied/non-block-aligned sizes and both networks. No production-port capture. Compare ClientHello/ALPN and opaque lengths/timing, keeping synthetic matched controls separate from real browser. Use fresh sizes/validation, report false positives and limits; no censorship-probability estimate.
4. TCP feature/security decisions: bounded first version; decide multiplexing from measured cost/benefit, no automatic application replay or unsafe stream resume. Credential rotation/revocation, tests, parser/resource fuzzing and vulnerability checks. Manual source audit is an internal audit, not an independent review of new cryptography. TLS1.3 primitives remain standard.

Each stage has its own artifacts and pass/limitation status. Incomplete external validation must stay listed even while independent later implementation progresses. Questions go through the popup, while independent work continues. Restore phone network settings and lab services after experiments.
