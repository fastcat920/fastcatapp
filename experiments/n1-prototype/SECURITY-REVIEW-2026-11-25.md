# N1 TCP 原型内部安全审查

范围：本目录的认证、记录层、目标访问、取消与关闭、资源限制、凭证和内存TLS缓存。内部代码审查、自动化测试和已知漏洞扫描；不是第三方密码审计，也不是不可识别性证明。

|检查项|落实与验证|剩余边界|
|---|---|---|
|密码与信任|标准TLS1.3、CA/名称验证；HMAC-SHA256绑定TLS exporter、方法/路径、时间、nonce和目标。跨连接重放、错key/名称、过期授权测试|共享PSK分发不是完整账号体系；不设计新密码原语|
|重放与重试|8192项/60秒有界去重；仅认证前最多一次可选瞬态重试；证书/HTTP拒绝不重试；已有业务不重放|进程级状态，不提供跨实例重放数据库|
|解析|记录大小/载荷/填充/序号/FIN严格检查、粘性EOF、拒绝截断；四个解析入口有界模糊测试|一分钟左右的fuzz不能证明不存在漏洞|
|目标边界|显式数值目标；公共域名名单+实际连接IP校验；阻止DNS重绑定到私网及特殊地址；数字端口校验|管理员显式允许的本机测试源有意绕过公共目标策略；不是完整出站防火墙|
|权限与秘密|配置/凭证环私有普通文件、进程所有、禁符号链接、大小上限；日志/元数据不输出凭证、Cookie或TLS密钥|未做操作系统密钥库、硬件保护、内存擦除保证|
|凭证生命周期|1..4密钥、有效期、递增版本、原子替换+SIGHUP；坏配置保留有效版本；禁用全部无回退；活动租约再次检查并关闭|单节点控制面；不含面板、计费、多实例一致性|
|恢复与隔离|有界TLS内存缓存按凭证、网络代次、入口、CA等隔离；复用TLS必须再次授权；无0-RTT|网络代次需调用方正确维护；尚非正式App网络监听实现|
|资源|64入口/32会话、默认8/源、2分钟业务上限、头预算、目标5秒；取消释放目标和入口；指标文件私有、有界、排他写入|NAT共享额度；未做生产账号公平性/流量配额/分布式防护|
|本机测试代理|只监听loopback、有界连接和头超时、半关闭保留反向上传；配置范围外目标本机拒绝|是实验辅助进程，未替换正式VPN|
|依赖|无第三方运行依赖。Go1.26.2扫描命中16项可达标准库漏洞后，使用官方校验和的独立Go1.26.11重新构建，复扫无已知漏洞|扫描是当前数据库快照；不能替代逻辑和密码审查|

已修复的关键问题：建连上下文影响已建立业务、服务端/客户端TLS预算错配、关闭错误链与完成标记不清、半关闭提前丢反向上传、缓存缺少凭证隔离、私有配置读取未硬性校验权限/符号链接、测试代理未知目标仍建立外层握手、旧标准库已知漏洞。不存在把这些修复等同于已修复物理Wi-Fi丢包或GFW阻断的依据。

当前无法据此交付为大规模生产协议。至少仍需独立审计、更多网络/设备长期试点、正式App接入与切网生命周期、部署/监控/回滚和账号计量验收。UDP按用户选择暂缓；外层多路复用和业务恢复明确不纳入首版。
